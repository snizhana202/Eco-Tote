# 🌿 EcoTote

Односторінковий лендинг магазину екологічних сумок.

🔗 **Демо:** https://eco-tote-silk.vercel.app

## Опис

Проєкт стартував як командне завдання під час курсу [GoIT](https://goit.global/) і продовжує самостійно розвиватись — з новими фічами, покращеннями верстки та рефакторингом.

## Технології

- HTML5, CSS3
- JavaScript (ES-модулі)
- [Vite](https://vitejs.dev/) — збірка проєкту
- [Lucide](https://lucide.dev/) — іконки
- Деплой: [Vercel](https://vercel.com/)

## Функціонал

- 🧭 Плавна навігація по сторінці з фіксованим header
- 📱 Мобільне бургер-меню з іконками
- 🛒 Модальне вікно оформлення замовлення з JS-валідацією полів (ім'я, телефон, адреса) у реальному часі
- 📩 Форма зворотного зв'язку з власною JS-валідацією
- 🔔 Toast-сповіщення після успішного оформлення замовлення чи відправки форми
- ⭐ Динамічна генерація рейтингу у відгуках клієнтів
- 📐 Адаптивна верстка (мобільна / планшетна / десктопна версії)

## Структура проєкту

src/
├── css/ # стилі, розбиті по секціях
├── img/ # зображення та іконки
├── js/ # логіка (модалка, меню, валідація, toast)
└── partials/ # HTML-партіали для кожної секції


## Запуск локально

```bash
git clone https://github.com/snizhana202/Eco-Tote.git
cd Eco-Tote
npm install
npm run dev
```

Проєкт буде доступний за адресою, яку покаже термінал (зазвичай `http://localhost:5173`).

### Збірка для продакшену

```bash
npm run build
npm run preview
```
